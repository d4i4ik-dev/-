# Мои сайты — перенос с Lovable

## Сайт VIBE (vibe-business)

- `мой-сайт/` — исходный код сайта VIBE (React / TanStack Start), выгружен с Lovable.
- `готовый-сайт/` — собранный сайт (статические HTML-файлы), готов к загрузке на любой российский хостинг.
- `ИНСТРУКЦИЯ-ПЕРЕНОС-НА-РОССИЙСКИЙ-ХОСТИНГ.md` — пошаговая инструкция: хостинг, домен, загрузка, SSL.
