# Мои сайты

## biznes-na-ai.ru — Дарья Попельнюк, цифровая мастерская

Сайт-визитка: сайты, боты и AI-инструменты для бизнеса. Пересобран под новое
позиционирование (личная цифровая мастерская), светлый чистый дизайн.

- `мой-сайт/` — исходный код сайта (React / TanStack Start). Здесь редактируется контент и дизайн.
- `готовый-сайт/` — собранный сайт (статические HTML-файлы), готов к загрузке на хостинг.
- `site.zip` — тот же собранный сайт одним архивом для загрузки в файловый менеджер.
- `ИНСТРУКЦИЯ-ПЕРЕНОС-НА-РОССИЙСКИЙ-ХОСТИНГ.md` — пошаговая инструкция: хостинг, домен, загрузка, SSL.

Разделы сайта: Главная, Сайты, Боты и AI, Мини-приложения, Кейсы, Статьи, Контакты.

### Как обновить сайт после правок кода

```
cd мой-сайт
npm install
npm run build      # соберёт статику в мой-сайт/dist/client
```

Затем содержимое `мой-сайт/dist/client` загрузить на хостинг (или обновить `готовый-сайт/` и `site.zip`).
