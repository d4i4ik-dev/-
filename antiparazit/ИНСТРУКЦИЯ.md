# Антипаразитарный курс — установка на Тильду

| Файл | Что это |
|---|---|
| `tilda-block.html` | Весь сайт одним куском кода для блока T123 (~72 КБ) |
| `images/` | 3 картинки — лежат в GitHub, код грузит их оттуда автоматически |
| `template.html`, `build.py` | Служебные файлы для внесения правок (можно не трогать) |

## Установка

1. Создайте в Тильде пустую страницу.
2. Добавьте блок **Другое → T123 «HTML-код»**.
3. Вставьте в него всё содержимое `tilda-block.html`.
4. Настройки блока: ширина **100%**, отступы сверху/снизу **0**.
5. В редакторе Тильды блок может выглядеть криво — оценивайте только
   опубликованную страницу (кнопка «Опубликовать»).

SEO-настройки страницы (Настройки страницы → Главное):
- Title: `Антипаразитарный курс Юлии Сурминой — глубокая перезагрузка организма за 40 дней`
- Description: `Авторская программа очищения по натуропатии: кишечник, кровь, лимфа, печень, почки. 17 лет практики, 7000+ исцелённых. Личное сопровождение Юлии Сурминой.`

## Что где менять

- **Цены** — поиск по `45 000` и `69 500` (каждая встречается 2 раза: тариф и финальная кнопка).
- **Ссылки на оплату** — поиск по `payform.ru` (4 шт.).
- **Telegram / WhatsApp / MAX / Instagram** — поиск по `t.me`, `wa.me`, `max.ru`, `instagram`.
- **Цвета** — переменные в начале `<style>`: `--ap-gold` (золото), `--ap-bg` (изумрудный фон) и т.д.
